# DevFlow AI

Small startup MVP / landing page created as a static website.

## Pages
- `index.html` — public landing page
- `login.html` — demo sign-in
- `dashboard.html` — demo workspace
- `style.css` — responsive styling

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload these files.
3. Import the repository into Vercel.
4. Deploy as a static site — no build command is required.

## Important
This is a prototype. The login uses demo-only client-side navigation and does not store real user credentials.
